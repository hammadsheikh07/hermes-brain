## TL;DR
- Self-improving AI agent by Nous Research; the "only agent with a built-in learning loop."
- Learning loop = agent-curated memory + autonomous skill creation + skill self-improvement + FTS5 recall.
- 6 backends (local, Docker, SSH, Daytona, Singularity, Modal); 20+ chat platforms via one gateway.
- Providers: Nous Portal, OpenRouter, OpenAI, custom. MCP + web tools (search, vision, TTS, image).
- MIT licensed; serverless backends hibernate when idle for near-zero idle cost.
