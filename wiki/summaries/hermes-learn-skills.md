## TL;DR
- `/learn` captures a workflow into a reusable skill from a directory, docs URL, past conversation,
  or pasted notes — no hand-writing.
- Skills are `SKILL.md` files (YAML frontmatter) in `~/.hermes/skills/`, agentskills.io-compatible.
- SKILL.md sections: description (<60 chars), When to Use, Procedure, Pitfalls, Verification.
- Progressive disclosure: ~3k-token index first, full content on demand.
- Four creation paths: hand-write, `/learn`, agent auto-save, Skills Hub. Announced 2026-06-23.
