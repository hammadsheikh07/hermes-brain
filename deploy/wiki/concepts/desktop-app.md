## Definition
The native Electron desktop surface for [[hermes-agent]], introduced as the headline of v0.16.0 and
expanded in v0.17.0 and v0.18.0. It moves Hermes beyond a terminal interface into a macOS/Linux/
Windows app. (source: raw/articles/2026-07-01-hermes-agent-releases.md)

## Details
- v0.16.0 introduced the desktop app with native install/update, remote gateway sign-in, chat UX,
  provider/settings management, dashboard integration, and Simplified Chinese localization. (source: raw/articles/2026-07-01-hermes-agent-releases.md)
- v0.17.0 deepened desktop UX with rebindable keyboard shortcuts, native notifications, live subagent
  watch-windows, external provider disconnect, VS Code Marketplace themes, terminals, cron jobs,
  remote media relay, and multi-profile cleanup. (source: raw/articles/2026-07-01-hermes-agent-releases.md)
- v0.18.0 added first-class coding Projects: a sidebar of codebases, coding rail, review pane, git
  worktree management, agent-facing project tools, and a `project -> repo -> lane` model. It also
  added a memory graph and many composer/thread/sidebar refactors. (source: raw/articles/2026-07-01-hermes-agent-releases.md)
